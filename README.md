## 贯穿所有案例的工作方法

1. **每个数字必须有来源、可追溯** — 假设溯源表 / 数据审计底稿是标配
2. **迭代留痕** — PPT 文件名即时间戳，7 版迭代过程完整保留
3. **先验证标杆再设计方案** — 不凭空想象，交叉验证上市公司年报 / 权威数据库
4. **敢复盘错误** — 关节海绵案例里主动记录了 3 个财务处理错误及修正
