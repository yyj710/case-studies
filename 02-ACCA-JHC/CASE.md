# 02 · ACCA JHC 就业力大比拼 — AI 碳管理公司战略规划

> **成绩**：华南区复赛（队长）| **角色**：财务分析 + 数据验证 | **周期**：2026.03–04

## 背景

C 公司是消费电子代工厂（对标富士康），营收 2,300 亿，72% 依赖北美大客户 B。B 要求 2026 年底前范围 3 碳数据溯源准确率从 62% 提升到 95%，否则砍 15% 订单（248.4 亿）。供应商数据错误率 38%，存在系统性漂绿。

## 我做了什么

### 1. 五层交叉验证体系（初赛核心产出）

单据核验 → 一致性比对 → 外部核实 → 实地勘察 → 不确定性评估（关键排放源 ±5%，总不确定性 ≤±10%，依据 GHG Protocol / ISO 14064）。复盘时发现与审计取证流程（凭证检查、分析性程序、函证、监盘、重要性水平）一一对应——**用审计思维做商业分析**。

### 2. CVP 本量利分析

15% 订单流失 → 净利润下降 **148.3%**（净利率仅 4.5%，经营杠杆放大效应）；10% 流失即逼近盈亏平衡。ROI 测算：5,000 万 CapEx，绿色贷款年省利息 1,500 万，ROI 30%，回收期 3.33 年。

### 3. 500 万项目双模式财务测算（复赛核心产出）

| 模式 | 结果 | 风险点 |
|------|------|--------|
| 里程碑模式（40%-30%-30%） | 净利率 16.5% | Q3 出现约 45 万现金流缺口，提出缓释机制 |
| EMC 模式 | 回本 3 年 | 首年净现金流 -304 万；同时做 2 个 EMC 项目将占公司年净利润 73.8% |

结论：新客户用里程碑控风险，成熟客户用 EMC 建长期关系，未来转 EMC+订阅混合。

### 4. 数据审计底稿（最审计味儿的产出）

为验证"订阅制客单价 10 万/年"假设，做了 8 列底稿：数据类别 → 假设数值 → 来源 → 链接 → 验证状态 → 证据截图 → 权威性说明 → 数据摘要。用 **7 个独立数据源**交叉验证（延凡科技、数晰智能、阿里云能耗宝、EcoVadis、Convene ESG、Salesforce Net Zero Cloud 等）。

## 结果

带队进华南区复赛（未进决赛）。最大收获：形成"**每个数字必须有来源、可追溯**"的工作习惯。
